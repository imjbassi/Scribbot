PRINT NEXT: MG90S MOTOR MOUNT ONLY

Print ONE COPY of each of the two STL files in this folder.
01 contains all FOUR motor posts.
02 contains all FOUR backing plates.
Total new pieces: EIGHT. Do not print four copies of either file.

PLA, 0.4 mm nozzle, 0.12 mm layer height, 0.2 mm first layer,
100% scale, 4 walls, 100% infill, no supports. Keep parts flat as exported.

The ALREADY-PRINTED-REUSE subfolder contains the previously fitted servo
plate and small gear for completeness. Reuse yours; print replacements
only if missing. The turntable you assembled does not need reprinting.

See ASSEMBLY_DIAGRAM.png and ASSEMBLY_STEPS.md.
The guide calls the new files posts_set_of_4.stl and shoes_set_of_4.stl;
these correspond to 01 and 02 here.

This stage checks unloaded motor placement and gear height.
The 10 mm posts are provisional pending the installed gear-height check.
Horn-to-gear fastening remains unresolved; this is not a powered-drive release.
